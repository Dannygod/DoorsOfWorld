# DoorsOfWorld

[博物館網站](https://dannygod.github.io/DoorsOfWorld/)

## English
An interactive museum exhibition exploring war-related gate and door architecture from Eastern and Western civilizations. Featuring historic Chinese frontier passes and European medieval city gates with dynamic galleries and responsive design.

## 繁體中文
互動式博物館展覽網站，展示中國長城關隘與歐洲城門等戰爭門類建築。透過動態圖片輪播和詳細歷史介紹，帶領訪客探索建築如何塑造人類文明與歷史。
